## TurboDiffusion: Accelerating Video Diffusion Models by 100–200 Times

### Jintao Zhang123∗, Kaiwen Zheng1∗, Kai Jiang12∗, Haoxu Wang1∗, Ion Stoica3, Joseph E. Gonzalez3, Jianfei Chen1, Jun Zhu12†

1Tsinghua University, 2Shengshu Technology, 3UC Berkeley, †Corresponding author https://github.com/thu-ml/TurboDiffusion

### Abstract

We introduce TurboDiffusion, a video generation acceleration framework that can speed up endto-end diffusion generation by 100–200× while maintaining video quality. TurboDiffusion mainly relies on several components for acceleration: (1) Attention acceleration: TurboDiffusion uses low-bit SageAttention and trainable Sparse-Linear Attention (SLA) to speed up attention computation. (2) Step distillation: TurboDiffusion adopts rCM for efficient step distillation. (3) W8A8 quantization: TurboDiffusion quantizes model parameters and activations to 8 bits to accelerate linear layers and compress the model. We conduct experiments on the Wan2.2-I2V-A14B-720P, Wan2.1-T2V-1.3B-480P, Wan2.1-T2V-14B-720P, and Wan2.1-T2V-14B-480P models. Experimental results show that TurboDiffusion achieves 100–200× speedup for video generation on a single RTX 5090 GPU, while maintaining comparable video quality. The GitHub repository, which contains model checkpoints, training, and inference code, is available at https://github.com/thu-ml/TurboDiffusion.

### 1 Method

We first describe the main techniques used in TurboDiffusion in Section 1.1. Then we introduce the training process and inference-time acceleration details of TurboDiffusion in Section 1.2 and Section 1.3.

- 1.1 Main Techniques TurboDiffusion mainly uses four techniques to accelerate diffusion models. First, TurboDiffusion uses SageAttention [1–4] for low-bit quantized attention acceleration; specifically, TurboDiffusion uses the SageAttention2++ [3] variant. Second, TurboDiffusion uses Sparse-Linear Attention (SLA) [5] for sparse attention acceleration. Since sparse computation is orthogonal to low-bit Tensor Core acceleration, SLA can build on top of SageAttention to provide cumulative speedup. Third, TurboDiffusion uses rCM [6] to reduce the number of sampling steps, which is currently a state-of-the-art diffusion distillation method. Through model weights merging, rCM naturally inherits attention-level accelerations. Finally, TurboDiffusion uses W8A8 quantization for Linear layer acceleration. Specifically, the data type is INT8 and the quantization granularity is block-wise with a block size of 128 × 128.

- 1.2 Training

Given a pretrained video diffusion model, TurboDiffusion performs the following training process. First, we replace full attention with Sparse-Linear Attention (SLA) [5] and finetune the pretrained model to adapt to sparsity. In parallel, we use rCM [6] to distill the pretrained model into a student model with fewer sampling steps. Second, we merge the parameter updates from both the SLA finetuning and the rCM training into a single model. All training can utilize either real or synthetic data.

Please see our GitHub Code for more details.

- 1.3 Inference

Given a video generation model trained with Sparse-Linear Attention (SLA) [5] and rCM [6] as described in the previous section, we deploy inference-time acceleration as follows.

Attention acceleration. We replace SLA with SageSLA, which is a CUDA implementation of SLA built on top of SageAttention.

Step distillation. We reduce the number of sampling steps from 100 to a much smaller value, e.g., 4 or 3.

Linear layer quantization. First, we quantize the Linear layer parameters to INT8 with a block-wise granularity of 128 × 128. Second, during inference, we also quantize the activations in Linear layers to INT8 with the same block-wise granularity and use INT8 Tensor Cores to perform the Linear layer computation. In this way, we compress the model size by roughly half and achieve faster Linear layer computation.

Other optimizations. We reimplement several other operations, such as LayerNorm and RMSNorm, using Triton or CUDA for better efficiency. Please see our GitHub Code for more details.

#### 2 Evaluations In this section, we evaluate the efficiency and video quality of TurboDiffusion.

##### 2.1 Setup

Models and baseline. We evaluate TurboDiffusion on Wan2.2-I2V-A14B-720P, Wan2.1-T2V-1.3B-480P, Wan2.1-T2V-14B-720P, and Wan2.1-T2V-14B-480P video diffusion models. We use the official implementation of Wan [7] (denoted as Original) and FastVideo [8] as our main baselines.

Hyper-parameters. We set the Top-K ratio to 0.1, corresponding to 90% attention sparsity, and use 3 sampling steps. In practice, we recommend using a Top-K value in the range [0.1,0.15] and setting the number of steps

to 4 to consistently achieve the best video quality. For fastvideo, we use the default parameters in the official implementation (3 sampling steps and 0.8 sparsity in attention).

GPU. Our primary inference experiments are conducted on a single RTX 5090 GPU. In addition, although the speedup is not as large as on the RTX 5090, we also observe substantial acceleration on other GPUs, such as RTX 4090 and H100.

##### 2.2 Efficiency and Quality

We compare the video generation quality and efficiency of the Original, FastVideo, and TurboDiffusion. For efficiency evaluation, we report the end-to-end diffusion generation latency, excluding the text encoding and VAE decoding stages. The following figures present visual comparisons on Wan2.2-I2V-A14B-720P, Wan2.1-T2V-1.3B-480P, Wan2.1-T2V-14B-720P, and Wan2.1-T2V-14B-480P, respectively. Since FastVideo does not provide an accelerated Wan2.2-A14B-I2V-720P, we only compare TurboDiffusion with Original on Wan2.2-A14B-I2V-720P.

From the figures below, we can see that TurboDiffusion not only achieves the highest efficiency but also maintains the video quality, demonstrating clear superiority to FastVideo.

### 3 Conclusion and Future Work

We present TurboDiffusion, a video generation acceleration framework that achieves 100–200× end-to-end diffusion speedup with negligible quality degradation. TurboDiffusion combines low-bit attention (SageAttention), Sparse-Linear Attention (SLA), step distillation via rCM, and W8A8 quantization, together with several additional engineering optimizations. Experiments on Wan2.2-I2V-A14B-720P, Wan2.1-T2V-1.3B-480P, Wan2.1-T2V-14B-720P, and Wan2.1-T2V-14B-480P demonstrate that TurboDiffusion reduces the generation time of a single video to <1 minute on a single RTX 5090 GPU, making high-quality video generation substantially more efficient and practical.

For future work, we plan to extend this framework to support more video generation paradigms, such as autoregressive video diffusion.
